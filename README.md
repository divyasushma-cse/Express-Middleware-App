# ExpressJS Middleware

## Live Deployment

**Live API:** [Open Express Middleware API](https://express-middleware-app-98xz.onrender.com)

**Patient API:** [View All Patients](https://express-middleware-app-98xz.onrender.com/api/v1/patients)

## Technologies Used
- Node.js
- Express.js
- CORS
- Morgan
- JavaScript

## Features
- Six types of Express middleware
- Patient CRUD operations
- Request logging using server.log
- Input validation
- Error handling
- 404 Not Found handling

## API Endpoints

| Method | Endpoint | Operation |
|---|---|---|
| POST | /api/v1/patients | Create |
| GET | /api/v1/patients | Read all |
| GET | /api/v1/patients/:id | Read by ID |
| PUT | /api/v1/patients/:id | Update |
| DELETE | /api/v1/patients/:id | Delete |
